## Quick checklist (legacy)

This was the v1 checklist before we wrote the quickref. It glossed over several steps that turned out to matter — A2P timing, calendar integration nuance, and the source-of-truth issue between VAPI's UI and the `Clients.system_prompt` column. Use the quickref instead.

- [ ] Client signs agreement
- [ ] Client returns discovery form
- [ ] Set up VAPI assistant (default persona: Wren)
- [ ] Provision Twilio number
- [ ] Submit A2P registration
- [ ] Configure n8n workflows
- [ ] Test happy-path call
- [ ] Test escalation call
- [ ] Go live
- [ ] Send welcome email
- [ ] Add to dashboard
- [ ] 48-hour check-in
- [ ] 7-day check-in
